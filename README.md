# Living Rust

## Overview
Living Rust is a plugin designed to enhance gameplay by introducing advanced AI behaviors, inventory management, and building mechanics. This project aims to create a dynamic and immersive experience for players.

## Project Structure
The project is organized into several folders, each serving a specific purpose:

- **Core**: Contains essential configuration, data management, logging, and constants.
- **Managers**: Manages various game elements such as NPCs, saving/loading game state, and configuration settings.
- **Models**: Defines the data structures and enums used throughout the plugin.
- **AI**: Implements AI logic, including decision-making processes and state management for NPCs.
- **Navigation**: Handles navigation and pathfinding for NPCs.
- **Combat**: Manages combat interactions and behaviors.
- **Inventory**: Oversees the inventory system for players and NPCs.
- **Building**: Facilitates building mechanics within the game world.
- **World**: Manages the game world and environmental interactions.
- **Utilities**: Provides helper functions and utilities for various tasks.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project in your preferred C# development environment.
3. Restore the project dependencies.
4. Build the project to ensure everything is set up correctly.

## Usage
- To start using the plugin, integrate it into your game environment as per the provided documentation.
- Refer to the individual files in the Core, Managers, AI, and other folders for specific functionalities and implementation details.
